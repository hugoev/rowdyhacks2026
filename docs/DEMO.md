# Stage handoff

Use three windows with the same origin: `/protected`, `/guardian`, `/relative`. Put the guardian on the main screen and the protected/relative screens on two phones or secondary windows. Only scripted mode is needed for the reliable P0 presentation.

## Before starting

- Start the server and confirm the green live-connection indicator.
- Set the family safe word in Family settings.
- Turn on the warning voice and test its speaker button once; use visible warnings if the venue blocks audio.
- Reset the demo from the guardian view. Do not reset midway through a demonstration.
- Keep the callback window connected.

## Short pitch

“Scammers don’t need to break into the vault. They convince someone to open it. Tripwire adds a second set of ears and a second key before the money moves.”

1. In Rosa’s shield, open **Check a call**, then expand **Presenter controls**. Run **The Grandson Job** and advance the lines. Point out family emergency, urgency, and secrecy as specific warning signs.
2. Open **Check the family word** and give the wrong answer. Open **Ask Alex**, then choose **Check with Alex** through the separate callback screen. Alex answers no.
3. Switch to **Send money** and attempt the $2,500 gift-card payment. The call guard keeps running while Rosa switches tasks. Show the held payment and the server-owned cooling-off deadline.
4. Elena denies it. Show **HEIST FOILED**, then its case file and the concrete tells.
5. Inspect a romance example. If Gemini is configured and has been checked, inspect a screenshot.
6. For an optional second beat, run a scenario in `/drill` and show its scored protective choices. The voices are scripted; this does not use the microphone.
7. Open `/weather` and point out the seeded-data disclosure before showing the 30-day San Antonio chart.

“AI is a tool; empathy is the strategy. You did nothing wrong by pausing.”

## Honest answers

- **Is this a real payment?** No. The payment state machine and persistence are real; funds and rails are simulated.
- **Is the callback an SMS?** No. It reaches an independently paired browser view over Socket.IO.
- **Is it listening now?** Only if Rosa explicitly enables microphone mode. Scripted mode never uses the microphone.
- **What does AI do?** With a key, Gemini enriches call signals and inspects screenshots. Payment enforcement remains deterministic; Gemini can asynchronously add a guardian summary for held payments.
- **What if APIs fail?** Text rules, scripted calls, local holds, callback, and browser voice still work. Image-only analysis reports unavailable rather than inventing a verdict.
- **Does it hang up the call?** No. It tells Rosa to hang up on her phone and stops the guard.
- **What is simulated?** Dollar payments, the practice-call dialogue, and Scam Weather counts. The on-chain escrow is devnet only. No ordinary phone call, SMS, or bank rail is connected. Presage is intentionally out of scope; real bank payments are not connected.
